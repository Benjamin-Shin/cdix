# 하드웨어 구성 권장안

## 하드웨어 스팩

### A안: 가장 저렴한 시작

* RTX 4090 24GB (700)
* RAM 128GB
* 24B INT4
* 동시 사용자 1명 중심

> 이건 PoC/내부 검증에는 좋다. 다만 병원 납품 장비로는 ECC 부재와 여유 부족이 걸린다. RTX 4090은 24GB 메모리를 제공하지만 엔터프라이즈급 ECC 메모리 제품은 아니다.

### B안: 내가 가장 추천하는 병원 납품형

* RTX 6000 Ada 48GB (1700) 또는 L40S 48GB (1300)
* RAM 256GB ECC
* CPU 24~32코어
* NVMe 4TB 이상
* 10GbE

> 이게 가장 균형이 좋다. 24B를 안정적으로 굴리고, 추후 32B급도 일부 검토할 수 있고, ECC까지 챙길 수 있다. L40S와 RTX 6000 Ada는 둘 다 48GB ECC 메모리를 제공한다.

### C안: 여유 있게 가는 상급형

* L40S 2장 (1300 * 2) 또는 H100 80GB (4000) 1장
* RAM 256~512GB
* CPU 32코어 이상

> 이건 동시 사용자, 긴 문서, 장기 확장성까지 보는 구성이야. CDIX 1차 도입에는 과할 수 있지만, 병원 전체 문서자동화 플랫폼으로 커질 걸 예상하면 나쁘지 않다.
